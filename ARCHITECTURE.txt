================================================================================
                              SCALABILITY DESIGN
================================================================================

HORIZONTAL SCALING:
┌─────────────────────────────────────────────────────────────────────────┐
│  Load Balancer                                                          │
│       │                                                                 │
│       ├──▶ API Instance 1 (Handles 1000 users)                         │
│       ├──▶ API Instance 2 (Handles 1000 users)                         │
│       ├──▶ API Instance 3 (Handles 1000 users)                         │
│       └──▶ API Instance N (Handles 1000 users)                         │
│                                                                         │
│  Total Capacity: N × 1000 users                                        │
└─────────────────────────────────────────────────────────────────────────┘

VERTICAL SCALING:
┌─────────────────────────────────────────────────────────────────────────┐
│  Increase Resources:                                                    │
│  • CPU: 2 cores → 4 cores → 8 cores                                    │
│  • RAM: 4GB → 8GB → 16GB                                               │
│  • Storage: SSD with higher IOPS                                       │
│                                                                         │
│  Result: Handle more concurrent requests per instance                  │
└─────────────────────────────────────────────────────────────────────────┘

DATABASE SCALING:
┌─────────────────────────────────────────────────────────────────────────┐
│  MongoDB Sharding:                                                      │
│  • Shard 1: Users A-M                                                   │
│  • Shard 2: Users N-Z                                                   │
│  • Shard 3: Exams & Questions                                           │
│  • Shard 4: Responses & Results                                         │
│                                                                         │
│  Replication: Primary + 2 Replicas per Shard                           │
└─────────────────────────────────────────────────────────────────────────┘
